## 📡 API Contract

Base URL (Android Emulator): `http://10.0.2.2:8000`  
Base URL (Physical Device / Web): `http://<YOUR_LAN_IP>:8000`

### `GET /api/live/aqi`
Returns current AQI readings for all monitored wards.
```json
[
  {
    "timestamp": "2026-05-30 14:00:00",
    "ward":      "Silk Board",
    "aqi":       142.0,
    "pm25":       71.0,
    "congestion": 63.5
  }
]
```

### `GET /api/history/aqi?ward=All&days=7`
Returns historical readings for chart/heatmap rendering.
```
Query params:
  ward   string  Ward name or "All" for city aggregate
  days   int     Look-back window (default: 7)
```

### `GET /api/forecast/aqi`
Returns 24-hour XGBoost AQI baseline forecast.
```json
[{ "timestamp": "2026-05-31 00:00:00", "ward": "City", "aqi": 118.0, "pm25": 59.0, "congestion": 45.0 }]
```

### `POST /api/forecast/whatif`
Runs adjusted forecast given scenario parameters.
```json
// Request body
{ "trafficAdjust": -20.0, "rainMm": 3.5 }

// Response — same shape as GET /api/forecast/aqi
[{ "timestamp": "...", "ward": "City", "aqi": 101.0, "pm25": 50.5, "congestion": 36.0 }]
```

### `GET /api/traffic/junctions`
Returns telemetry for traffic monitoring junctions.
```json
[{ "junction": "Silk Board", "lat": 12.917, "lng": 77.623, "congestion": 78, "avg_speed_kmph": 14.2 }]
```

## ⚡ Quick Start

### Prerequisites
| Tool | Version |
|------|---------|
| Flutter | ≥ 3.22 (stable) |
| Dart | ≥ 3.4 |
| Python | ≥ 3.9 |
| Android Studio / Emulator | API 26+ |

### 1. Clone & Install
```bash
git clone https://github.com/<your-handle>/urbanpulse.git
cd urbanpulse

# Backend
cd backend
pip install -r requirements.txt
python -m uvicorn main:app --reload --port 8000

# Flutter app (new terminal)
cd ../urbanpulse_app
flutter pub get
dart run build_runner build --delete-conflicting-outputs  # regenerate *.g.dart
```

### 2. Run on Android Emulator
```bash
# Ensure emulator is running (API 26+)
flutter run -d emulator-5554
# Backend is reachable via http://10.0.2.2:8000 automatically
```

### 3. Run on Web (localhost)
```bash
flutter run -d chrome
# For web the backend needs CORS enabled (already configured in main.py)
```

## 🔬 Data Science Pipeline

```
data/raw/aqi_*.csv          ← CPCB OpenData scrape (daily)
        ↓  Streamlit EDA (urbanpulse/src/)
data/processed/merged.csv   ← AQI + traffic merged on ward × hour
        ↓  XGBoost training (notebooks/model_training.ipynb)
backend/model.pkl           ← Trained XGBoost regressor (MAE ≈ 8.3 AQI units)
        ↓  FastAPI serving
urbanpulse_app/             ← Flutter mobile + web consumer
```

**Model Features**: hour, day_of_week, congestion_pct, pm25, ward_encoded, rolling_24h_avg_aqi  
**Target**: `aqi` (next-hour prediction)  
**Validation RMSE**: 11.4 | **MAE**: 8.3 | **R²**: 0.87

## 🎨 Design System

| Token | Value | Usage |
|-------|-------|-------|
| `bgDark` | `#0F172A` | App background |
| `bgCard` | `#1E293B` | Glass card base |
| `primary` | `#4F46E5` | Accent, sliders, charts |
| `success` | `#10B981` | AQI Good (≤50) |
| `warning` | `#F59E0B` | AQI Moderate (51–100) |

## 🎓 Viva Notes

- **Why Riverpod?** — Compile-safe providers, no BuildContext required, `ref.invalidate()` for clean PTR
- **Why XGBoost?** — Tree ensembles handle non-linear AQI spikes from traffic events better than LSTM for tabular data
- **Why CartoDB Dark tiles?** — License-free, designed for dark-mode overlays, no API key required
- **Glassmorphism rationale** — `BackdropFilter` is GPU-accelerated on both iOS and Android Impeller renderer
